# SQLP 과목 III 튜닝 스타일 모의문제

![문항](https://img.shields.io/badge/문항-20-1f6feb)
![원본창작](https://img.shields.io/badge/원본-창작(clean--room)-2ea44f)
![라이선스](https://img.shields.io/badge/license-CC%20BY%204.0-blue)

SQLP(SQL 전문가) 자격시험 **과목 III — SQL 고급활용 및 튜닝**을 대비하기 위한 **원본 모의문제 20선**입니다. 실제 실전문제집 한 권의 과목 III 121문항을 집계해 얻은 **출제 통계(장·절 분포, 문제유형 비율, 함정 패턴, 자극물 밀도)와 난이도 특성**을 재현했습니다.

## ⚠️ 상용 교재와 무관한 원본 창작입니다

- 이 문제들은 **어떤 교재의 문항도 전사·복제하지 않았습니다.** 통계와 개념 지식만으로 **새 시나리오·새 수치·새 테이블명**으로 창작(clean-room)했습니다.
- 그래서 저작권 제약이 없어 자유롭게 공유·활용할 수 있습니다(CC BY 4.0).
- 재현한 것은 *출제 형식과 난이도*이지 특정 문항이 아닙니다.

## 난이도 — 실제 시험 수준을 목표로

얇은 "예상문제"가 아니라 실전 수준의 밀도를 목표로 했습니다.

- **정통 TKPROF 트레이스**(Call 7열 + Row Source Operation)를 읽고 CF·BCHR·ArraySize를 **직접 계산**하는 문항.
- **10행 이상 병렬/파티션 실행계획**, **다분할 파티션 DDL**, **TX×t 타임라인·Lock 모니터링 결과표**.
- 오답은 자극물의 **실제 수치·플랜 노드에 결부**되어, 계산 없이는 소거되지 않습니다("항상/반드시" 같은 티 나는 표현을 쓰지 않습니다).
- 실행계획은 실제 실전문제집이 쓰는 **구식 포맷**을 따릅니다(A-Rows/Buffers/Predicate Information 같은 현대 요소는 쓰지 않습니다).

## 구성 — 회차별 디렉토리

문항은 **회차(N회차)** 단위로 나뉩니다. 공통 파일(README·LICENSE·AGENTS·도구)은 최상위에 두고, 각 회차 세트는 자체 디렉토리에 담습니다. 이번이 **1회차**이며 앞으로 회차가 추가됩니다.

| 경로 | 내용 |
|---|---|
| `1회차/문제/mock-01.md … mock-20.md` | 1회차 문항 원본(발문·선택지·정답·해설). 진실 공급원 |
| `1회차/모의고사_1회차.pdf` | 1회차 시험지 PDF (문제부 + 정답·해설부) |
| `1회차/커버리지.md` | 1회차가 커버한 개념·함정·분포·자극물 밀도 요약 |
| `AGENTS.md` | 문항 스키마·품질 스펙·함정 카탈로그 (전 회차 공통) |
| `_tools/verify.py` | 규약 검증(정답 자기정합·오답표·시대착오/밀도 가드) |
| `_tools/render.py` | md → 시험지 PDF 렌더러 (실행계획 표를 디스플레이 폭으로 자동 정렬) |

## 검증

모든 문항은 정답 정확성을 **독립 검증**합니다 — 명시 정답이 유일하게 옳은지, 각 오답이 실제로 틀린지, 트레이스·실행계획의 수치가 실제로 맞는지 직접 계산해 확인합니다.

```bash
python _tools/verify.py 1회차     # 규약 게이트 20/20 (회차 생략 시 1회차)
python _tools/render.py 1회차     # 1회차/모의고사_1회차.pdf 생성
```

> 렌더러는 실행계획·트레이스 표의 ASCII 정렬을 위해 한글 고정폭 폰트(굴림체)를 씁니다. Windows 기준 경로가 `_tools/render.py` 상단 상수에 있습니다.

## 관련

출제 통계의 근거가 된 과목 III 분석은 별도(비공개) 저장소에서 다뤘습니다. 이 저장소는 그와 독립적이며 원본 창작물만 담습니다.
